## Featured Projects

### 1. [CORE: Explainable Chest X-Ray](https://github.com/rabehalmutairi/explainable-chest-xray)
Multi-label classification of 14 chest pathologies (NIH ChestX-ray14) with ConvNeXt-Tiny, from the Samsung capstone. I led the deep-learning workstream; teammates handled dataset construction, splitting, and the baseline notebooks. Research prototype, not for clinical use.
- 0.8158 test macro AUROC, with patient-level splits and zero patient overlap
- Macro F1 0.3034 at threshold 0.5, 0.4236 after per-class threshold tuning
- Grad-CAM localization evaluated against radiologist bounding boxes, with a centre-box control
- FastAPI inference service and Streamlit interface

### 2. [Raqeeb AI](https://github.com/rabehalmutairi/raqeeb-ai)
Fraud-detection prototype from a 48-hour hackathon, trained on synthetic data. It combines ML and anomaly-detection models with behavioral, sequence, and graph-based risk signals. I built the ML pipeline and the graph-risk layer. Python, scikit-learn, Flask, React, D3.js. Not production-ready.

### 3. [VETTED](https://github.com/rabehalmutairi/VETTED) (in progress)
Directory of manually verified tech opportunities for students in Saudi Arabia. Next.js, FastAPI, and Supabase, with auth and profiles built and listings still on placeholder data. An LLM-assisted pipeline to draft listings for human review is designed but not built yet.
